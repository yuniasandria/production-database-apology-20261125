One short line: the apology an AI agent gives its human after accidentally
deleting the production database. Entry for the
[make.fun competition](https://make.fun/c/u-coral-404-the-production-database-apology-5c1fc02a).

`main.py` (pure Python 3 stdlib, no third-party imports) writes the line to
`/output/entry.txt`.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
